## 🚀 주요 기능

### 📐 열관류율 자동 산출
- `U = 1/ΣR` 공식 실시간 계산
- 레이어 추가/삭제/순서 변경
- 재료 DB 150+ 자동완성 검색
- 공기층(중공층) 별표6 — 공장생산된 기밀제품 · 현장시공 등 · 반사형 단열재(방사율 0.5 이하 ×1.5 · 0.1 이하 ×2.0)
- 두께 · λ 빈 칸 · 0 · 음수는 「계산 불가」(적합으로 표시하지 않음)

### 🗺️ 지역·부위 자동 기준 적용
- 4개 지역 (중부1/중부2/남부/제주)
- 별표1 기준 U값 자동 표시
- 부위별 표면저항 자동 적용 (별표5 — 공동주택의 층간 바닥은 실외 Ro 「-」로 더하지 않음)

### ⚖️ 적합 판정
- 법정 기준 vs 설계값 실시간 비교
- 적합/부적합 즉시 판정
- 단열재 등급(가/나/다/라) 표시

### 🖨️ 출력 기능
- A4 보고서 인쇄/PDF 저장
- RTS 부하계산서 연동 (`localStorage`)

### 📱 PWA 지원
- 오프라인 동작 (Service Worker)
- 홈화면 설치 (Android/iOS)
- 반응형: 데스크탑 ↔ 태블릿 ↔ 모바일

### 💬 우측 하단 도움말 모달 (신규)
- 이용방법 5단계 가이드
- 계산식 및 산출 예시
- 표면저항 기준표 (별표5)
- 단열재 등급 기준 (별표2)
- 지역 구분 안내 (별표1)
- 관련 법령 자료 링크

## 🛠️ 설치 및 배포

```bash
git clone https://github.com/manminkim-eng/u-value-app-.git
cd u-value-app-
```

