00이 매뉴얼에 대하여

열관류율 종합 검토 시스템은 벽·지붕·바닥의 재료 구성을 입력하면 열관류율(U)을 계산하고, 「건축물의 에너지절약설계기준」 별표1 기준값과 비교해 적합 여부를 판정한 뒤 A4 계산서로 출력하는 웹 계산도구입니다. 처음 쓰는 건축·설비 기술자가 화면 순서대로 따라 하며 부위별 단열 구성을 검토할 수 있도록 작성했습니다.

025분 따라하기

외벽 한 부위를 예제로 8단계를 따라 하면 열관류율 0.160 W/㎡·K, 기준 0.240 이하 「적합」 계산서가 나옵니다. 예제 값은 프로그램을 처음 열었을 때 이미 들어 있으므로, 값을 바꿔 보며 결과가 달라지는 것을 확인하면 됩니다.

  1. 접속manminkim-eng.github.io/u-value-app- 를 엽니다. 「검토 조건 입력」 탭이 먼저 보입니다.
  2. 프로젝트명·설계자 입력「프로젝트명」과 「설계자(담당 건축사)」를 적습니다. A4 계산서의 공사명·작성자로 들어갑니다.
  3. 지역 구분 선택「지역 구분」에서 중부1지역·중부2지역·남부지역·제주도 중 하나를 고릅니다. 예제는 중부2지역입니다. 시·군별 구분은 4-3 표로 확인합니다.
  4. 부위·외기 조건·용도 선택「건축 부위」 거실의 외벽, 「외기 조건」 외기에 직접 면하는 경우, 「용도 / 난방 여부」 공동주택 외 를 고르면 「법적기준」 칸에 0.240이 표시되고, 아래에 별표3 등급별 허용 두께(가 135 · 나 155 · 다 180 · 라 200 mm)가 나옵니다.
  5. 재료층 구성「단열·재료 구성」에서 실외 쪽부터 실내 쪽으로 재료를 넣습니다. 대분류 → 중분류 → 재료를 고르면 열전도율 λ가 채워지고, 두께(mm)를 적으면 열저항 R이 계산됩니다. 예제는 시멘트몰탈 20 → 압출법보온판(XPS) 1종 A-1 155 → 철근콘크리트 200 → 시멘트몰탈 20 입니다. 층은 「+ 추가」로 늘리고 ✕로 지웁니다.
  6. 결과 확인오른쪽 「실시간 산출 결과」에 설계값 0.160 W/㎡·K, 판정 적합이 표시됩니다. 아래 「부위별 상세 산출 근거」에서 ΣR = 6.268 ㎡·K/W 를 확인합니다.
  7. A4 계산서 출력「A4 미리보기」 탭에서 계산서를 확인하고 「인쇄 / PDF 저장」 또는 「JPG 저장」을 누릅니다.
  8. RTS 부하계산 연계냉난방 부하계산이 이어지면 「RTS 부하계산 연계」 탭의 「U값 + 재료 데이터 → RTS 전송」을 누릅니다. 지붕·바닥은 3~7단계를 부위별로 반복합니다.
확인따라 한 결과가 ΣR 6.268 · U 0.160 · 적합이면 정상입니다. 다른 값이 나오면 부록 A1의 입력값과 비교하십시오.

화면에 보이는 순서대로 각 영역이 하는 일과 입력 방법을 설명합니다.

3-2. 단열·재료 구성

  • 층 순서는 실외 → 실내입니다. 왼쪽 번호가 산출 근거 표와 A4 계산서의 NO가 됩니다.
  • 열전도율 칸은 직접 고칠 수 있습니다. 납품 예정 단열재의 시험성적서 값이 DB 값과 다르면 성적서 값을 넣습니다.
  • 공기층은 대분류 「M 창호·공기층」에서 이름에 「공기층」이 들어간 재료를 고릅니다. 이때 열저항은 두께 ÷ λ 가 아니라 별표6 현장시공 값(두께 1cm 이하 0.086 × 두께(cm), 1cm 초과 0.086)으로 계산됩니다(4-5).
  • 표면 열전달저항(실내·실외)은 층으로 넣지 않습니다. 부위·외기 조건에 따라 자동으로 더해집니다.

3-3. 실시간 산출 결과

계산 버튼은 없습니다. 조건이나 층을 바꾸는 즉시 다시 계산됩니다. 열관류율은 소수점 넷째 자리에서 반올림해 셋째 자리까지 표시하고, 그 값으로 판정합니다(제6조제1호 다목 5)).

3-4. 부위별 상세 산출 근거

ΣR = Ro + R1 + R2 + … + Rn + Ri R = t(m) ÷ λ = 0.043 + 0.014 + 5.962 + 0.125 + 0.014 + 0.110 = 6.268 ㎡·K/W U = 1 ÷ 6.268 = 0.1595… → 0.160 W/㎡·K ≤ 0.240 적합

3-5. 부적합일 때

부적합이면 단열재 두께를 늘리거나 열전도율이 더 낮은 재료로 바꿉니다. 예제 구성에서 압출법보온판 1종 A-1(λ 0.026)은 101mm 이상이면 U 0.239로 적합합니다(100mm는 0.241로 부적합). 별표3의 가등급 허용 두께 135mm보다 얇아도 계산으로 기준을 만족하면 적합하며, 두 방법 중 하나만 만족하면 됩니다(4-1).

3-6. A4 미리보기·출력

  • 공사명·작성자는 「검토 조건 입력」 탭의 프로젝트명·설계자가 그대로 들어갑니다. 작성일은 출력하는 날 날짜입니다.
  • JPG 파일 이름은 열관류율_검토계산서_MANMIN-Ver5.0_날짜_시각.jpg 형식입니다.
  • PDF에 색이 빠지면 인쇄 창 「설정 더보기」의 「배경 그래픽」을 켭니다.

3-7. A4 계산서 구성

계산서는 부위 1개에 1장입니다. 외벽·지붕·바닥을 모두 검토하면 부위별로 출력해 묶습니다.

3-9. RTS 부하계산 연계

전송을 누르면 RTS-MANMIN 냉난방 부하계산서가 새 창으로 열리고, 현재 부위의 U값과 재료 구성이 전달됩니다. 두 도구는 같은 주소(manminkim-eng.github.io) 아래에 있어 같은 브라우저에서만 연계됩니다. 팝업이 차단되면 주소창에서 허용한 뒤 다시 누릅니다.

3-10. 계산식 안내·초기화

3-11. 모바일
